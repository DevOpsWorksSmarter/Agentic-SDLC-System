Context

The Problem

Why SDLC automation matters

Requirements are ambiguous

Engineers waste hours clarifying vague specs before writing a single line of code. "Make it scalable" means nothing without concrete targets.

SDLC steps are disconnected

Architecture, code, tests, and docs are produced in silos with no shared context. Each handoff loses information and introduces drift.

No controlled autonomy

Either fully manual (slow, expensive) or fully automated (risky, no oversight). There is no middle ground that gives engineers control.

Brownfield work is opaque

Changing existing systems without understanding the full impact surface causes regressions, breaking changes, and missed migrations.

Human-in-the-Loop Gates

Design

System Architecture

Three-phase pipeline with shared blackboard state

Phase 1 — Requirement Understanding

RequirementAgent classifies scenario, detects & resolves ambiguities, normalizes requirement, extracts constraints and success criteria.

Phase 2 — Task Decomposition

DecompositionAgent breaks requirement into ordered tasks with explicit depends_on, assigns agents, injects into WorkflowState.

Phase 3 — Dependency-Aware Execution

Orchestrator runs ready tasks in parallel, handles approval gates, retries (max 2), skips dependents on failure or rejection.

Key Design Decisions

Shared WorkflowStateSingle blackboard — no message passing overhead
REJECTED is terminalHuman rejection propagates skip-dependents identically to failure
html.escape on inputXSS prevention before any string interpolation
Path confinementAll writes verified within declared output directory
auto_approve flagFull CI/CD execution without interactive prompts
Zero external depsNo LLM API keys — fully deterministic and reproducible

Hardened across the full codebase — identified and fixed during review

Path TraversalHIGHoutput_writer.py, codebase_reasoning_agent.py_safe_segment() sanitizes path components; _safe_join() uses realpath + startswith check
Hardcoded CredentialsHIGHcode_generation_agent.py (docker-compose)${POSTGRES_PASSWORD:?} — fails fast if env var not set; DATABASE_URL uses same var
Non-Root ContainerMEDIUMDockerfilegroupadd/useradd appuser (UID 1000); runAsNonRoot: true in K8s securityContext
Naive DatetimeLOWstate.py, base.pyAll datetime.now() calls use timezone.utc — no naive datetime objects
Dot-Segment BypassMEDIUMoutput_writer.py_TRAVERSAL regex blocks pure-dot segments (..) after sanitization
Multi-Stage BuildLOWDockerfileBuilder stage separate from runtime; python:3.12-slim — no build tools in production image
